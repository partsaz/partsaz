# 🎭 ماژول اکشن فیگور (Figure Module)

این ماژول مسئول ساخت مدل سه‌بعدی از عکس و مفصل‌بندی آن است.

## 🎯 هدف

کاربر چند عکس آپلود می‌کند
AI با ECON/PIFuHD مدل سه‌بعدی می‌سازد
مفصل‌بندی (Ball joint، Peg، Magnet)
خروجی STL برای چاپ سه‌بعدی

## 📁 ساختار

- `image-to-3d/` — تبدیل عکس به مدل
- `joints/` — طراحی اتصالات
- `templates/` — الگوهای آماده

## 🚀 وضعیت

- [ ] آشنایی با ECON
- [ ] آشنایی با PIFuHD
- [ ] اولین مدل از عکس
- [ ] اولین مفصل
- [ ] اکشن فیگور کامل
