# 🔧 ماژول مکانیکی (Mechanical Module)

این ماژول مسئول ساخت قطعات مکانیکی پارامتریک با CadQuery است.

## 🎯 هدف

کاربر می‌گوید: «شاتون ۲۰۶ می‌خواهم»
AI پارامترها را استخراج می‌کند
CadQuery مدل سه‌بعدی می‌سازد
خروجی STL برای چاپ سه‌بعدی

## 📁 ساختار

- `examples/` — مثال‌های ساده برای یادگیری
- `templates/` — الگوهای پارامتریک قطعات واقعی
